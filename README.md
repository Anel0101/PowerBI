#  San Francisco Bikeshare Analytics
### Анализ поведения пользователей системы велопроката с помощью Power BI

##  О проекте

Учебный аналитический проект, посвящённый исследованию использования системы совместного использования велосипедов San Francisco Bikeshare.

Цель проекта — изучить поведение пользователей, выявить закономерности поездок, определить периоды наибольшей активности и проанализировать популярность станций и маршрутов.

В рамках проекта создан интерактивный дашборд в Microsoft Power BI, позволяющий исследовать динамику поездок и характеристики пользовательской аудитории.

##  Цели и задачи исследования

Основная цель — выявить закономерности использования сервиса и определить особенности поведения различных категорий пользователей.

## Данные

Данные использовались для изучения временных характеристик поездок, станций отправления и назначения, типов подписки и демографических характеристик пользователей.

### 1. Temporal Analysis — временная динамика поездок

Анализ изменения количества поездок в зависимости от временных периодов.

Основные показатели:
- Количество поездок по годам.
- Распределение поездок по месяцам.
- Количество поездок по кварталам.
- Динамика использования сервиса в течение исследуемого периода.

**Основные наблюдения:**
- Наибольшее годовое значение за полный календарный год зафиксировано в 2017 году — около 519,7 тыс. поездок.
- Среди месяцев наиболее высокие значения наблюдаются в апреле (215 тыс.) и октябре (203 тыс.).
- За анализируемый период показатели по кварталам варьируются от 396,09 тыс. до 536,45 тыс. поездок.

### 2. Usage Patterns — активность пользователей и популярность станций

Исследование временных паттернов использования сервиса и наиболее востребованных станций.

Основные показатели:
- Распределение поездок по часам суток.
- Сравнение активности по дням недели.
- Рейтинг популярных станций отправления.
- Наиболее популярные маршруты.

**Основные наблюдения:**
- Наибольшая активность наблюдается около 08:00 и 17:00.
- Вторник является днём с максимальным количеством поездок.
- Среди наиболее популярных станций выделяются San Francisco Caltrain (Townsend at 4th), San Francisco Caltrain 2 и Harry Bridges Plaza.

### 3. User Demographics — характеристики пользователей

Анализ структуры пользовательской аудитории и распределения поездок по категориям.

Основные показатели:
- Доля Subscriber и Customer.
- Средний возраст пользователей.
- Распределение поездок по гендерным категориям.
- Активность пользователей по дням недели.

**Основные наблюдения:**
- На подписчиков (Subscriber) приходится около 84% всех поездок.
- На категорию Customer приходится около 16%.
- Средний возраст пользователей в отчёте составляет 43 года.
- Наибольшая доля записей в гендерном распределении относится к категории Not specified.

*Проект выполнен в образовательных целях для развития навыков анализа данных, исследования поведения пользователей и визуализации аналитических результатов.*
